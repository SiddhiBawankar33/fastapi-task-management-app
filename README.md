# FastAPI Task Management App

A REST API for managing tasks, built with Python and FastAPI.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy&#x20;

## Features

- Create a task
- Retrieve all tasks
- Retrieve a task by ID
- Update a task
- Delete a task

## Project Structure

- `main.py` — application entry point
- `src/tasks/` — task-related routes, controllers, models, and schemas
- `src/user/` — user-related code
- `src/utils/` — database and utility modules

## Setup

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the dependencies from `requirements.txt` (or your actual dependency filename).
4. Create a local `.env` file with the required configuration.
5. Start the FastAPI development server:

   `fastapi dev main.py`
